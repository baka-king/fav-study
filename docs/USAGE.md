# 使用教程

> 第一次打开软件时会自动显示这一页；以后可以从「设置 → 使用教程」再看。

## 一、准备

1. **AI Key**：去你常用的模型服务（DeepSeek、通义千问、OpenAI 兼容接口都行）申请一个 API Key。
2. **账号**：手机上装好抖音、小红书，用来扫码登录。

## 二、四个步骤

### 1. 填 AI Key

打开「设置 → AI 提炼」：

- 选服务商（DeepSeek / 通义 / 自定义）
- 填 API Key
- 点「测试连接」，看到成功提示即可

AI 只在这两件事上花钱：把文字稿提炼成笔记、给收藏自动分类。分类是本地规则优先，AI 只处理没把握的。

### 2. 登录账号

打开「添加与处理」：

- **登录抖音**：会弹一个浏览器窗口，用抖音 App 扫码；登录状态会一直保存在本机
- **登录小红书**：页面中间直接弹二维码，用小红书 App 扫码，扫完自动关窗

页面最上方会显示两个平台的登录状态，右边有「刷新登录状态」按钮，随时可以核对。

### 3. 同步收藏

同一页：

- 抖音：选「我的收藏」或「我的喜欢」，点 **开始同步**
- 小红书：选「最近 50 条」或「全部」，点 **同步收藏**

之后全自动：读取信息 → 下载 → 本地转文字（视频）/ 识别图片文字（图文）→ AI 提炼 → 自动分类。

> 「生活与娱乐」类内容默认跳过不拆解；想看的话，进详情页点「还是处理这条」。

### 4. 开始学习

- **汇总 / 抖音 / 小红书**：三个视图分别浏览两个平台或全部收藏，顶部搜索框随时搜标题、作者
- **学习库**：按分类复习，可以标记已学、星标、导出 PDF / Markdown
- **本地缓存**：缓存过的视频直接读本地文件，点开秒播

## 三、小技巧

### 视频切换

- 详情页或播放器里，视频左右两侧有 **‹ ›** 按钮
- 键盘 **↑ / ↓** 切换上一条 / 下一条
- **Esc**：关闭播放器；在详情页则返回进来时的列表

### 右键菜单（卡片上）

- **播放原视频**
- **取消收藏并删除**：平台里取消收藏 + 删掉本地缓存 + 记录进回收站
- **复制原链接**

卡片右上角还有两个快捷按钮（✕ 取消收藏、🗑 删除），鼠标移上去才出现。

### 本地缓存

缓存页像下载工具：显示每个文件的进度、速度、总占用，可以「缓存全部视频」或「清空缓存」。

> 注意：部分电脑的安全软件会阻止程序删除文件，此时缓存会被改名成 `.deleted` 藏起来（应用里视为已删），磁盘空间需要手动清理。

### 重复内容 / 查重

「重复内容」页会把内容相近的收藏分组，选一条留下，其余移到回收站。

## 四、常见问题

**同步到一半停了？**
关掉浏览器窗口或网络抖动都可能导致中断，重新点同步即可，已读到的不会重复添加。

**转文字很慢？**
第一次会下载语音模型（几百 MB），之后走本地 CPU。可以把设置里的「最大时长」调小，超长的视频会跳过。

**笔记存哪了？**
设置里可以指定笔记文件夹，默认在 `data/notes`，都是 Markdown 文件。

**换电脑怎么迁移？**
设置里有备份与恢复：导出备份文件（可选是否包含密钥），在新电脑恢复即可。
