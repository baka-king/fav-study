# 启动方式（后台运行 / 打开界面）

这个应用分两层：**后台服务**（负责同步收藏、下视频、转文字、AI 提炼）和**界面**（浏览器里的页面）。
关掉界面不会停掉后台服务，所以不需要一直开着窗口。

## 两种双击入口

| 双击 | 会发生什么 | 适合 |
| --- | --- | --- |
| **后台运行.vbs** | 只起服务 + 右下角托盘图标，**不弹浏览器**。右键托盘：打开界面 / 暂停同步 / 打开日志 / 退出 | 开机后挂着，自动同步与处理 |
| **launch.vbs**（或 打开界面.vbs） | 服务没跑会先在后台拉起，然后开一个**没有地址栏**的窗口（Chrome `--app` 模式） | 想看内容时 |

## 几个要点

- **关窗口 ≠ 退出程序**。关掉窗口后后台仍在同步与处理；要彻底停掉，用托盘右键「退出」或界面「设置 → 退出程序」
- **不会重复开窗口**。界面每 5 秒打一次 `/api/heartbeat`，启动器据此判断：窗口还活着就只把它叫到前面
- **托盘图标可能在折叠区**。Win11 默认把新图标收进「隐藏的图标」，点 ^ 就能看到，可以拖到任务栏常驻
- **抖音同步不弹窗**。抓收藏用的浏览器窗口会移到屏幕外，不打断你
- **端口**：默认 `127.0.0.1:8765`，只监听本机，不对外

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `后台运行.vbs` | 起服务 + 挂托盘，不开窗口 |
| `launch.vbs` / `打开界面.vbs` | 调 `open_ui.ps1`：起服务（如需）→ 已有窗口就聚焦 → 没有才开窗口 |
| `open_ui.ps1` | 打开界面的实际逻辑（PowerShell，比 VBS 的 `Run` 稳） |
| `tray.ps1` | 托盘图标与右键菜单（PowerShell WinForms，自带单实例锁 `data/tray.lock`） |
| `start.bat` | 前台命令行启动，调试用（会占一个黑窗口） |

## 想开机自动跑

1. 右键 `后台运行.vbs` → 创建快捷方式
2. `Win + R` 输入 `shell:startup`，把快捷方式拖进去
3. 下次开机就会静默启动，右下角有托盘图标

## 排查

| 现象 | 处理 |
| --- | --- |
| 双击没反应、也没有托盘 | 看 `data/app.log` 最后几行；确认 `python\python.exe` 还在 |
| 托盘图标不见了 | 点任务栏 ^ 展开隐藏图标；或再双击一次 `后台运行.vbs`（不会叠图标） |
| 窗口打不开 | 直接浏览器访问 `http://127.0.0.1:8765/` |
| 想彻底退出 | 托盘右键「退出」，或任务管理器结束 `python.exe`（先删 `data/app.lock`） |
