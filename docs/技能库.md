# 技能库（把已解析的笔记排成能直接执行的清单）

收藏只是原料，技能库回答的是：**我现在该装什么、该动手做什么、哪些重复了、哪些可以删。**

打开方式：左侧栏 ★ 技能库（`#/skills`）。

## 只碰 AI 与学习类

整理的分类固定为这 9 类，娱乐/美食/健身/穿搭/摄影一律不进来：

AI 编程 · AI 工具推荐 · AI 绘画与视频 · AI 副业与变现 · AI 办公效率 · AI 学习方法 ·
提示词技巧 · 学习与成长 · 大模型与行业资讯

## 六个分区（互不重叠，不存在浮层）

| 分区 | 内容 | 你能做什么 |
| --- | --- | --- |
| 可执行 | 按优先级 P1–P5 排好的清单，前 24 条带大脑点评（为什么适合你 / 今天就能做的第一步） | 打开来源笔记、标为已装、不看这条 |
| 重复项 | 真重复（标题只差几个字 / 正文三元组重合度 ≥ 45%）+ 同一技能散落在多条笔记里 | 点开逐条看，自己决定留哪条；不会自动删 |
| 落后 / 建议删除 | 标题或工具名里出现旧版本、停服信号，或 120 天前的行业快讯 | 点「移入回收站」，可恢复 |
| 已装 | 本机 `which` 探测到、或你手动标为已装的 | 取消已装 |
| 暂缓 | 大脑明确说「先别动 / 本机已有 / 没增量」的 | 改回可执行 |
| 已忽略 | 你手动屏蔽的 | 恢复 |

## 数据怎么来的

1. **笔记本身**：`data/library.db` 里 done 状态的条目，只取上面 9 类。
2. **本机全局情况**（`_local_state()`）：`which` 探测 codex / claude / node / git / python / yt-dlp / ffmpeg / code / docker / obsidian，
   当前模型与 provider，以及记忆库 `00_规则.md` 里**白名单行**（只保留技术/工作偏好，
   涉及负债、体检、用药、案件、房产、现金、体重、睡眠的一律跳过，绝不上云）。
3. **大脑审查**：每 14 条一批、最多 70 条，交当前模型（SCNet-Max，失败回退 Magpie）给
   `priority / why / action`，并要求结合第 2 步的本机情况判断「值不值得装」。
4. **校验**：封面必须是 `/files/...` 且文件真实存在（≥512 字节、路径含该条 `aweme_id`），
   否则一律显示色块占位，绝不拿远端图或别的条目的封面凑；本地 Markdown 缺失的笔记直接被过滤。

## 优先级怎么理解

- **P5**：本机条件已经齐了，今天就能动手，且和你手上的事直接相关
- **P4**：值得本周排进计划
- **P3**：可作为备选
- **P2**：知道就行，暂时别投入
- **P1**：明确「先别动 / 跳过 / 没增量」——已经自动归到「暂缓」，不会占可执行清单
