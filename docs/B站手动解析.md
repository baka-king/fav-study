# B 站（手动解析，不做自动同步）

## 为什么和抖音/小红书不一样

抖音、小红书是「登录一次 → 后台每 10 分钟自动同步收藏」。
B 站账号是和别人共用的，自动同步会互相顶号、也会读到别人收藏的东西，
所以 **B 站只做手动一次性解析**：你贴一条地址，就解析这一条。

## 怎么用

1. 打开 B 站视频页，复制地址（`bilibili.com/video/BV...`，`b23.tv` 短链也认）
2. 软件 →「添加与处理」→ 粘贴框 → 粘贴 → 点「添加并插队」
3. 侧边栏「收藏」里会多一个「B站」标签，可以只看 B 站的内容

## 解析流程

```
粘贴地址
  → 取标题/作者/时长/封面/简介（官方接口）
  → 有官方字幕：直接用字幕（最快，不用转写）
  → 没字幕：用 yt-dlp 下音频 → 本机转文字 → AI 提炼成笔记
```

封面会存到本地 `知识库/_图片/<BV号>/cover.jpg`，不依赖会过期的图床链接。

## 依赖

- `yt-dlp`：本机已装（winget），代码里会自动在常见路径找它；
  找不到时会提示 `没找到 yt-dlp，装一个再试（winget install yt-dlp）`
- 不需要 B 站登录也能解析大部分公开视频；需要登录才能看的（大会员/私密）会下载失败并给出提示

## 和自动模式的关系

自动同步只覆盖抖音、小红书。B 站不会出现在自动同步里，
也不会因为你贴过一条就去拉整个收藏夹 —— 这是刻意设计的。
