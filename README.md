# 收藏学习台 · FavStudy

把 **抖音 / 小红书 / B站** 的收藏，自动整理成能读、能学、能复习的本地笔记。

一个跑在自己电脑上的 Windows 桌面应用：同步收藏 → 下载视频/图片 → 本地转文字或识别画面文字 → AI 提炼成笔记 → 自动分类。**所有数据都在本机**，笔记是可被 Obsidian 直接打开的 Markdown 文件。

> 本项目由 **@baka-king** 在原版基础上改进与维护。原始版本：[@yuanshengbo8-sketch/douyin-fav-study](https://github.com/yuanshengbo8-sketch/douyin-fav-study)，按 `LICENSE.md` 的 PolyForm Noncommercial 1.0.0 保留原署名。

## 功能

### 内容来源
- **抖音**：收藏 / 喜欢，后台每 10 分钟自动同步
- **小红书**：收藏，扫码登录后自动同步
- **B站**：**手动粘贴**（B站号常是与人共用的，不做自动同步），支持 `BV号` / `b23.tv` 短链；有官方字幕直接用，没有就下视频转写 + 读画面文字

### 处理流水线（全自动，不用手点）
读取信息 → 下载（720p 优先，多源并行）→ 转文字（faster-whisper，短视频自动用更准的 medium）→ 画面文字（RapidOCR，**显卡加速**）→ AI 提炼 → 自动分类 → 写 Markdown

- **不丢内容**：没有旁白、画面也没字时，用标题/简介兜底也要出一条笔记，由你自己删
- **失败自愈**：暂时性错误 60 秒后自动重试（最多 3 次），连续失败进回收站
- **封面本地化**：封面存到本地，不再因图床签名过期变成空白
- **今日汇总**：当天新增 / 拆解完成 / 跳过统计 + 分类分布

### 学习与整理
- 笔记按 16 个分类归档，支持二级分类、搜索、列表/卡片两种视图、回收站
- **技能库**（`#/skills`）：把已拆解的笔记排成能直接执行的清单
  - 只整理 AI 与学习类 9 个分类，娱乐/美食/健身/穿搭不参与
  - 大脑结合**本机实际环境**（装了什么工具、用什么模型、记忆库里的技术偏好）逐条给
    「为什么适合你 / 今天第一步做什么 / 优先级 P1–P5」
  - 六个互不重叠的分区：可执行 / 重复项 / 落后建议删除 / 已装 / 暂缓 / 已忽略
  - 自动找重复：标题只差几个字、正文三元组重合度 ≥ 45%、同一技能散落多条，
    只列出来给你判断，**不会自动删**
  - 建议删除只认「标题或工具名里有旧版本/停服信号」或 120 天前的行业快讯，可一键移入回收站
  - 封面必须真实存在且属于该条笔记才显示，否则用色块占位；本地 Markdown 缺失的笔记直接过滤
  - 记忆库里涉及健康、财务、案件的内容**不会**进提示词，`focus` 也会先裁掉非 AI 话题
  - **按平台分类**：只看你「实际在用」的平台（默认 dsh + workbuddy），PATH 里探测到但没在用的不算；
    建议分 DSH / WorkBuddy / 通用三组，依赖 Codex、Claude Code 之类的技能自动移入暂缓
- 知识网络、周报、精读、测验、问老师
### 界面
- 三套外观：**浅色（默认）/ 纯白 / 深色**，侧栏小圆钮一键切换（设置里也能选）
- 侧栏「汇总 / 抖音 / 小红书 / B站」四个视图，分类实时计数

### 分类
- 内置**分类标准**（`docs/分类标准.md`）：每类写明收录什么、不收录什么、例子
- 拆解时按标准分类；分不出来的进「其他」，**不硬塞**
- 设置里有「自查分类」：按关键词体检全库，导出可疑条目报告（不花钱）

## 需要你自己配模型（重要）

这个应用**不自带任何 AI 额度**，用你自己的 Key：

1. 打开软件 →「设置」→「AI 提炼」
2. 选服务商（DeepSeek / 智谱 GLM / 硅基流动 / 任意 OpenAI 兼容接口 / 自建中转）
3. 填 **API Key**（和 Base URL、模型名，如果用自定义接口）
4. 点「测试连接」，成功会自动保存

也可以点「免费方案」，用各家的免费额度，不花钱但效果弱一些。
**建议**：先跑通免费，再决定要不要换付费模型。

> 语音识别（faster-whisper）和文字识别（RapidOCR）都是**本机运行**，不需要 Key，也不上传你的视频。

## 数据与隐私

- 仓库里**只有代码**，没有任何人的收藏、笔记、Cookie、API Key
- 运行时数据都在 `data/`（已被 `.gitignore` 排除）：
  - `data/library.db` 条目库、`data/知识库/` Markdown 笔记与图片
  - `data/settings.json` 你的 Key、`data/login.json`、`data/bili_cookies.txt` 登录态
- 所有请求只从你本机发往你选的服务商与对应平台；不上传第三方
- 备份功能导出的 zip 里如果勾选了「包含 AI Key」，请当作密码保管

## 快速开始（Windows）

1. 安装 **Python 3.12**（安装时勾选 *Add python.exe to PATH*）
2. 双击 **install.bat**（安装依赖 + 下载浏览器组件，几分钟）
3. 双击 **start.bat**（或 `launch.vbs` 无窗口启动）
4. 按「需要你自己配模型」填好 Key
5. 点「登录抖音 / 登录小红书」扫码；B 站视频直接把地址粘进「添加与处理」

### 命令行启动

```bat
python -m app              :: 打开窗口
python -m app --no-browser :: 只起服务，浏览器自己开 http://127.0.0.1:8765
```
