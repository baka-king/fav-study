# 收藏学习台

把**抖音**和**小红书**的收藏，自动整理成能读、能学、能复习的本地笔记。

一个跑在自己电脑上的 Windows 桌面小应用：同步收藏 → 下载视频/图片 → 本地转文字或识别图片文字 → AI 提炼成笔记 → 自动分类。所有数据都在本机，笔记是 Markdown 文件。

## 功能

- **两个平台**：抖音（收藏 / 喜欢）、小红书（收藏），互不混在一起；侧栏「汇总 / 抖音 / 小红书」三个视图切换
- **全自动处理**：读取信息 → 下载 → 本地转文字（faster-whisper）或图片文字识别（RapidOCR）→ AI 提炼 → 自动分类
- **学习库**：按分类复习、标记已学、星标、导出 PDF / Markdown、精读提问、知识网络、每周周报
- **详情页播放器**：左侧视频，右侧点赞/收藏/评论数据；左右箭头或 ↑ ↓ 切换上下条，Esc 退出
- **本地缓存**：视频缓存到本地，点开秒播；缓存页像下载工具一样显示进度、速度、占用
- **右键快捷操作**：取消收藏并删除（平台取消 + 清缓存 + 进回收站）、播放、复制链接
- **搜索**：侧栏顶部随时搜标题和作者

## 快速开始（Windows）

1. 安装 **Python 3.12**：<https://www.python.org/downloads/>，安装时勾选 **Add python.exe to PATH**
2. 双击 **install.bat**（安装依赖并下载浏览器组件，几分钟）
3. 双击 **launch.vbs** 启动（没装 Chrome 会用 Edge）
4. 首次打开会显示**使用教程**，跟着做：填 AI Key → 登录抖音/小红书 → 同步收藏

> 也可以用命令行运行：`python -m app`（调试用 start.bat）。

## 需要准备什么

- 一个 AI 模型服务的 Key（DeepSeek / 通义 / OpenAI 兼容接口都行），在「设置 → AI 提炼」里填
- 抖音、小红书账号（App 扫码登录，只登录一次，登录状态存在本机）

## 目录说明

```
app/            程序代码（Python + 原生 JS 前端）
launch.vbs      启动器：后台起服务，用 Chrome/Edge 应用窗口打开界面
data/           运行后生成：数据库、设置、缓存、浏览器登录态（不会提交到仓库）
```

## 隐私

- 所有数据只保存在你自己电脑的 `data/` 目录，不会上传到任何服务器（除了你配置的 AI 接口）
- 本仓库**不包含任何用户数据**：没有数据库、没有笔记、没有缓存视频、没有登录 Cookie、没有 API Key
- 卸载就是删掉整个文件夹

## 常见问题

**安装依赖很慢 / 失败？**
换国内镜像：`python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

**转文字很慢？**
第一次会下载语音模型（几百 MB），之后走本地 CPU。也可以在设置里把「最大时长」调小。

**登录窗口找不到？**
小红书登录是**页面内弹二维码**，不用找浏览器窗口；抖音会弹一个浏览器窗口，用完可以关掉。

**视频播放要等？**
没缓存过的第一次需要解析地址；缓存过的直接读本地文件。缓存页可以「缓存全部视频」。

**会不会封号？**
程序只是模拟正常浏览和收藏操作，但自动化操作仍有风险，请自行评估、低频使用。
